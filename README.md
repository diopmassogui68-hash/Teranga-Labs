# Téranga Labs — Site Web Officiel

Site officiel de **Téranga Labs**, agence digitale spécialisée dans la création de sites web, d'applications web, d'applications mobiles et la conception UI/UX.

## Direction artistique
- Identité strictement monochrome : `#000000`, `#FFFFFF` et nuances de gris neutres.
- Architecture React + Vite modulaire, responsive et accessible (`prefers-reduced-motion`).

## Démarrage rapide

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
npm run preview
```

## Personnalisation rapide
- **Contenus (services, projets, valeurs)** : `src/data/content.js`
- **Logo officiel** : `src/assets/logo/teranga-labs-logo.svg` et `src/assets/logo/teranga-labs-logo-white.svg`
- **Sculpture 3D Hero** : `src/assets/images/hero-tl-sculpture.jpg`
- **Coordonnées Email / WhatsApp** : `src/components/ContactModal.jsx`
